# Enterprise Perimeter Security Lab

A hands-on cybersecurity engineering project focused on designing, implementing, testing, and documenting security controls in a simulated enterprise network.

This repository records practical work on how network security technologies work together to protect an organization's systems, services, and data. The project originated from practical exercises in the **CY377 Enterprise Perimeter Security** course and is maintained as a personal learning and portfolio project.

## Objectives

- Understand enterprise network architecture and identify attack surfaces.
- Design network segmentation and apply least-privilege firewall policies.
- Configure and investigate network intrusion detection.
- Explore secure remote connectivity using virtual private networks (VPNs).
- Deploy and assess reverse proxies and web application firewalls (WAFs).
- Understand Zero Trust architecture and identity-aware access.
- Explore cloud network security and data protection controls.
- Investigate security events using security monitoring and SIEM concepts.

## Documentation Approach

Each lab will include relevant details such as objectives, key concepts, network topology, tools used, implementation steps, commands and configurations, verification evidence, security analysis, troubleshooting, and lessons learned.

Only tools, technologies, configurations, and results that have actually been used or verified will be documented as completed work.

## Learning Focus

The goal is not only to record configuration steps, but also to understand what each security control does, why it is needed, how it is configured and tested, how it interacts with other enterprise components, and what its limitations are.

## Security and Responsible Use

All activities are intended for educational purposes and authorized lab environments. Sensitive information such as passwords, API keys, private keys, VPN credentials, personal data, and confidential network details must be removed or replaced with safe examples before publishing. Do not use techniques against systems without permission.
